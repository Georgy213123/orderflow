# 07. Путь релизов

Версии по SemVer, изменения — в [CHANGELOG.md](CHANGELOG.md).
До 1.0 контракт API может меняться между минорными версиями.

## MVP → v0.1: заявка из текста

Задача: проверить главную гипотезу — менеджер тратит время на перенос текста.

- Вошло: создание заявки, разбор текста правилами, источник и фрагмент у поля,
  подтверждение и правка, статусы «новая» и «разобрана».
- Отложено: конструкция и смета. Без проверенных полей считать нечего, сначала
  нужно убедиться, что разбор находит большую часть полей.

## v0.2: конструкция изделия

- Вошло: параметрическая модель шкафа, спецификация деталей и фурнитуры,
  инварианты, статус «конструкция готова».
- Отложено: другие типы изделий (тумба, стеллаж с особой конструкцией). Тип изделия
  разбирается из текста, но модель пока одна — шкаф. Стеллаж без дверей описывается
  ей же.

## v0.3: смета — текущая версия демо (0.3.1 — исправления по ревью Codex, BUG-06…BUG-10)

- Вошло: смета по справочнику, коэффициент запаса, неполный итог, цены разных дат,
  статусы «смета готова» и «отправлена клиенту», адаптер уведомлений (заглушка).
- Исправлено: BUG-01…BUG-05.
- Отложено: экран справочника цен (правка через начальные данные), PDF сметы.

## Дальше до v1.0

| Версия | Что | Почему в этом порядке |
|---|---|---|
| v0.4 | Вход и права по ролям; экран справочника материалов с историей цен | без ролей нельзя пускать нескольких сотрудников; цены — источник ошибок из 01-problem.md |
| v0.5 | Адаптер языковой модели с откатом на правила; замер доли найденных полей на реальных заявках | решение принимать по замеру, а не по ощущению |
| v0.6 | Документы заказа: спецификация и бланк для цеха; отправка сметы клиенту реальным каналом | это первое, что попросит цех после сметы |
| v1.0 | Маршрут производства по ролям, обмен с учётной системой через `AccountingExporter` | требует отдельной сущности заказа и согласования формата обмена |

Не планируется: трёхмерная визуализация изделия, оптимизация раскроя внутри
OrderFlow (для раскроя есть специализированные программы, нужен только экспорт
спецификации).
