# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Версии — этапы сборки кейса: MVP, исправления по ревью, второй круг ревью.

## [Unreleased]
### Добавлено
- Интерфейс `AccountingExporter` и заглушка обмена с учётной системой.

## [0.3.4] — 2026-11-04
Находки второго круга ревью Codex.
### Исправлено
- BUG-13: статус «отправлена» ставился до отправки письма. Теперь сначала отправка с ключом идемпотентности, при сбое 502 и прежний статус, повтор разрешён.
- Параллельные сохранения полей в интерфейсе идут по очереди: поздний ответ раннего запроса не стирает свежие поля.
- Парсер понимает «120 на 210» (ширина и высота, см → мм), как в примере README.
### Изменено
- Контракт: ответ 502 у `POST /requests/{id}/transition`.

## [0.3.3] — 2026-11-04
Исправления по внешнему аудиту.
### Исправлено
- BUG-12: у числа полок и дверей не было верхней границы, теперь 10 и 4 (как в правилах конструкции), иначе 422.
- Интеграционные тесты падали на базе с чужой `alembic_version`: перед миграциями схема пересоздаётся (только на базе `*_test`).
- В итогах сметы подпись «Задняя стенка» стояла рядом с названиями материалов, теперь «ХДФ (задняя стенка)».
### Изменено
- Фронтенд собирается на Node 24, как в CI и README.
- `GET /api/health` в контракте без ответа 422.

## [0.3.2] — 2026-11-04
### Исправлено
- BUG-11: в смете нетто показывалось сырым Decimal, запас то «×1,15», то «×1,1». Теперь м² и м — 2 знака, штуки — целые, запас ×1,10; расчёт не менялся.

## [0.3.1] — 2026-11-03
Исправления по ревью Codex R-01…R-10, см. 04-ai-development.md.
### Исправлено
- BUG-06, BUG-07: смета от заменённой конструкции и двойная отправка — блокировка строки заявки, уведомление после фиксации статуса.
- BUG-08: интерфейс показывал данные другой заявки при переключении.
- BUG-09: интеграционные тесты работают только на базе `*_test`.
- BUG-10 и длинные значения полей: 422 вместо 500.
- Необязательное поле можно очистить; все 422 в контракте описаны моделью `Problem`; тест отправки проверяет уведомление.
