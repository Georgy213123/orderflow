## [0.3.1] — 2026-11-03

Исправления по независимому ревью Codex (R-01…R-10, см. 04-ai-development.md).

### Fixed
- BUG-06: смета могла остаться от заменённой конструкции — операции над заявкой
  идут под блокировкой строки.
- BUG-07: двойная отправка сметы; уведомление отправляется после фиксации статуса.
- BUG-08: интерфейс показывал конструкцию и данные другой заявки при переключении.
- BUG-09: интеграционные тесты отказываются работать на базе без суффикса `_test`.
- BUG-10: длинное число в тексте заявки давало 500.
- Значения полей длиннее 255 символов отклоняются с 422 вместо 500.
- Необязательное поле можно очистить («Убрать»).
- Контракт: все ответы 422 описаны моделью `Problem`.

### Changed
- Сквозной тест отправки проверяет получателя и сумму уведомления.

## [0.3.0] — 2026-11-03

### Added
- Смета по спецификации: площадь плиты по материалам, кромка в погонных метрах,
  фурнитура в штуках, коэффициент запаса из справочника.
- Признак неполного итога для строк без цены и запрет отправки неполной сметы.
- Предупреждение о ценах разных дат.
- Статусы «смета готова» и «отправлена клиенту», история переходов.
- Адаптер уведомлений `ClientNotifier` с заглушкой `LogNotifier`.
- e2e-сценарии Playwright для десктопа 1440 × 900 и телефона 390 × 844.

### Changed
- Деньги хранятся в целых копейках, количества — `Decimal` (ADR-0003).

### Fixed
- BUG-01: площадь детали округлялась до суммирования.
- BUG-05: деньги во float теряли копейку.

## [0.2.0] — 2026-10-28

### Added
- Параметрическая модель шкафа и спецификация деталей с кромкой по сторонам.
- Проверка инвариантов: пределы размеров, полки по высоте, ширина двери, лист плиты,
  толщина материала.
- Статус «конструкция готова»; правка конструкции удаляет устаревшую смету.

### Fixed
- BUG-02: полка шире внутреннего проёма проходила проверку.

## [0.1.0] — 2026-10-24

### Added
- Заявка из свободного текста или пустой формы.
- Разбор текста правилами: тип изделия, габариты, полки, двери, имя, телефон, почта.
- Источник поля «найдено в тексте» / «ввёл человек» и фрагмент исходного текста.
- Подтверждение и правка полей, статусы «новая» и «разобрана».
- Интерфейс `RequestParser` и адаптер языковой модели с откатом на правила.

### Fixed
- BUG-03: разбор текста путал сантиметры и миллиметры.
- BUG-04: повторное подтверждение поля сбрасывало источник.
