# 01. Постановка задачи

«Кедр» — вымышленная мастерская корпусной мебели на заказ. Заявки приходят свободным
текстом в почту и мессенджеры. Менеджер переписывает их в таблицу и уточняет недостающее,
конструктор считает детали на бумаге, смету считают по своей копии прайса. Руководитель
пересчитывает итог за менеджером.

## Боль

Числа — допущения, их надо проверять замером.

| Проблема | Допущение |
|---|---|
| ручной перенос текста | 10–15 минут на заявку |
| путаница единиц, забытая толщина плиты | каждая десятая смета пересчитывается |
| у каждого своя версия прайса | расхождение итога до 5 % |
| статус непонятен, ответ долгий | 2–3 рабочих дня до сметы |

## Успех и проверка в демо

| Критерий | Проверка |
|---|---|
| смета в тот же день | сквозной e2e без ручного счёта |
| вручную только ненайденное | разбор находит 9 полей образцового текста |
| ноль ошибок единиц | тесты «80 см» / «800 мм» / «0,8 м» |
| итог воспроизводим | 12 331,96 ₽ в unit, integration и e2e |
| у заявки статус и история | переходы проверяет сервер |

## Границы

Входит: приём заявки, модель шкафа, смета, статусы. Вне рамок:
производство, документы, раскрой, склад, учётная система, кабинет клиента, роли и вход.
