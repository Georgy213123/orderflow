# ADR-0001. Стек: FastAPI + PostgreSQL + React

Статус: принято, 2026-11-03.

**Контекст.** Нужны REST API, расчёт сметы без потери копеек, блокировки строк при параллельных
действиях менеджеров и интерфейс, которым удобно пользоваться с телефона. Код пишут агенты,
поэтому стек должен ловить ошибки до запуска.

**Варианты.** 1) FastAPI + PostgreSQL + React. 2) Django REST Framework. 3) NestJS + Prisma.

**Решение.** Вариант 1: Python 3.12, FastAPI, SQLAlchemy 2 и Alembic, PostgreSQL 16; фронт —
React + TypeScript strict на Vite; e2e — Playwright. OpenAPI выгружается из кода и сверяется
тестом, mypy strict ловит ошибки сгенерированного кода. `Decimal` и `NUMERIC` есть из коробки
([ADR-0003](0003-money-in-kopecks.md)), `SELECT … FOR UPDATE` нужен для сметы и отправки.

**Последствия.**
- Админку справочника, как в Django, придётся писать самому.
- Два рантайма (Python и Node), два набора линтеров и lock-файлов.
- Интеграционные тесты идут на настоящем PostgreSQL: гонки на SQLite в памяти воспроизводятся иначе
  ([04](../../04-ai-development.md#что-я-из-этого-вынес)).
